# סרטון הסבר ל-Shan-AI ב-Gemini Notebook (NotebookLM)

קהל יעד: **הנהלה בכירה**. שפה: **עברית**. טון: שיווקי, אבל מסביר את הלוגיקה של כל מודול.

## קבצים

| קובץ | מה זה |
|---|---|
| `01_shan-ai_source.pdf` | **המקור להעלאה** — ארבעת המודולים, הלוגיקה, ה"למה". בלי נתוני פרויקטים. |
| `01_shan-ai_source.docx` / `.txt` | אותו תוכן, אם PDF לא עולה. `.md` הוא קובץ העריכה בלבד — ה-Notebook לא מקבל אותו. |
| `../manual/sources/*.md` | אופציונלי: פרקי מדריך המשתמש (החלטות, שאל, זיכרון). מוסיף עומק למודול ההחלטות בלבד. |

> **אל תעלו** את קובץ המאסטר, צילומי מסך עם שמות פרויקטים/אנשים, או ייצוא מהמערכת. הקבצים מסומנים כמידע פנים, וה-Notebook הוא שירות ענן של Google.

## שלבים

1. `notebooklm.google.com` → **Create new notebook**.
2. **Add source → Upload** → `01_shan-ai_source.pdf` (רק אותו, לסרטון הראשי — מקור אחד = סרטון ממוקד).
3. ⚙️ (Settings) → **Output language → עברית**.
4. Studio → **Video Overview** → ✏️ (העיפרון, לא הכפתור עצמו):
   - **Format:** `Explainer` (הארוך והמובנה; הפורמט שתומך בעברית בוודאות).
   - **Visual style:** `Custom` → הדביקו את "סגנון ויזואלי" למטה. חלופה בטוחה: `Classic`.
   - **Focus:** הדביקו את "פרומפט ראשי" למטה.
5. Generate. בדקו מול הצ'קליסט בסוף. לא טוב? מחקו ונסו שוב עם התיקון בפרומפט — כל הרצה שונה.

## סגנון ויזואלי (Custom)

```
אינפוגרפיקה תאגידית נקייה ומודרנית. רקע כחול-כהה (#0e1020), הדגשות טורקיז (#00d4ff), סגול-בהיר וירוק. מוטיבים של תחנת משנה חשמלית: קווי מתח גבוה, שנאים, מפסקים. אייקונים פשוטים, כרטיסים ולוחות מחוונים בסגנון חדר בקרה. טקסט על המסך בעברית, מיושר לימין. בלי אנשים מצוירים, בלי סגנון מצויר-ילדותי.
```

## פרומפט ראשי (סרטון אחד, כל 4 המודולים)

```
צור סרטון הסבר שיווקי בעברית להנהלה בכירה בחברת חשמל (סמנכ"ל ומעלה) על Shan-AI — מערכת הבינה התפעולית של אגף פרויקטים לתחנות משנה.
מבנה:
1. פתיחה (כ-30 שניות): הכאב — אגף של 500 איש, מידע מפוזר, דוח שבועי שמראה רק את השבוע הזה, החלטות לא מתועדות, לקחים נשכחים, יעדים שזזים בשקט.
2. עיקרון העל: "ה-AI כותב, הכללים מחליטים" — אף מודל לא מחשב מספר, כל תשובת AI מאומתת.
3. ארבעה פרקים בסדר הזה: החלטות, פרויקטים, לקחים, חדר מבצעים. בכל פרק: הבעיה במשפט אחד, איך זה עובד צעד אחר צעד, ולמה אפשר לסמוך על זה.
4. סיום: איך ארבעת המודולים מתחברים למעגל אחד, ושש הסיבות שזה שווה להנהלה.
טון: בטוח, חד, מכירתי — אבל כל טענה מוסברת בלוגיקה שמאחוריה. הדגש בכל פרק את המנגנון שמונע טעות: גלאי הזזת תוכנית בסיס, דרגות טיפול לפי כלל, סיבה חובה לדחיית יעד, AI שלא ממציא ציטוטים.
אל תמציא מספרים, לקוחות, תוצאות או חיסכון כספי שלא מופיעים במקור. השתמש במונחים: מנה"פ, סמנכ"ל, תחנת משנה, חשמול, RACI.
```

## אופציה ב׳ — סדרה: סרטון לכל מודול (מומלץ אם הראשי יוצא שטחי)

סרטון של ~8 דקות על 4 מודולים = ~2 דקות למודול. אם זה שטחי מדי — צרו 4 סרטונים, כל אחד עם אותו מקור ופרומפט ממוקד:

```
סרטון הסבר שיווקי בעברית להנהלה בכירה, רק על מודול <שם המודול> של Shan-AI (פרק <מספר> במקור). פתח בבעיה שהמודול פותר, הסבר את הלוגיקה צעד אחר צעד, הדגש את המנגנון שמונע טעויות, וסיים במשפט אחד שמחבר אותו לשאר המערכת. אל תמציא מספרים או תוצאות שלא במקור.
```

| מודול | פרק במקור | המנגנון להבליט |
|---|---|---|
| החלטות | 1 | סיווג + RACI + אישור בטלגרם + תשובות זהב |
| פרויקטים | 2 | גלאי הזזת בסיס + 4 דרגות טיפול לפי כלל + אימות AI |
| לקחים | 3 | אשף טלפון ב-2 דקות + רפרנט אחראי + לקחים שנכנסים להחלטות |
| חדר מבצעים | 4 | אייזנהאואר + סיבה חובה לדחייה + מסך קיר "מי שותק" |

## צ'קליסט לפני שמראים לסמנכ"ל

- [ ] "Shan-AI" נהגה באופן סביר. אם לא — הוסיפו לפרומפט את ההגייה הרצויה בכתיב עברי.
- [ ] ארבעת המודולים מופיעים, בסדר הנכון.
- [ ] הטקסט על המסך בעברית ומיושר נכון (סגנונות מסוימים מעוותים RTL — אז חזרו ל-Classic).
- [ ] אורך סביר להנהלה: מעל ~10 דקות → עברו לאופציה ב׳.
- [ ] בדקו גם Audio Overview באותו מקור — לפעמים הוא החומר הטוב יותר לנסיעה.
