# 2. התחברות וסיור

## כניסה למערכת

1. היכנס/י לכתובת המערכת.
2. הקלד/י כמה אותיות משמך בשדה החיפוש — הרשימה מצטמצמת — ובחר/י את שמך.
3. הקלד/י סיסמה. אם לא הגדרת — ברירת המחדל היא `1234` (החלף/י מיד בפרופיל האישי).
4. לחיצה על "⏻ ENERGIZE" תעביר אותך לדשבורד.

- **זכור אותי במכשיר זה** — בפעם הבאה שמך כבר יהיה בחור. נשמר רק השם, לעולם לא הסיסמה. "החלפת משתמש" מבטל.
- **⚡ סרטון פתיחה** ו-**▶ צפה בסרטון ההסבר** — סרטון היכרות קצר עם המערכת, בלי צורך בכניסה.
