# 6. רשימת ההחלטות

בעמוד "📋 החלטות" רואה/ה את כל ההחלטות — שלך, של הצוות, ואלה שמחכות לאישור שלך.

## הצבעים והאיקונים

| תווית | משמעות |
|---|---|
| 🔵 מידע (INFO) | לוג בלבד, אין צורך בפעולה |
| 🟢 רגיל (NORMAL) | לוג + הודעות + ביצוע |
| 🔴 קריטי (CRITICAL) | דורש אישור בעל סמכות לפני ביצוע |
| 🟡 לא ודאי (UNCERTAIN) | דורש בירור ידני |
| ⏳ ממתין | עדיין לא אושרה |
| ✅ מאושר | בעל הסמכות אישר — תבוצע |
| ❌ נדחה | לא תבוצע |
| ⚡ בוצע | הפעולה בוצעה בפועל |
| ⛔ לא רלוונטי | סומנה כלא רלוונטית (עם סיבה) — נשארת לתיעוד, לא נספרת |
| 🏗 מזהה פרויקט | מקושרת לפרויקט — לחיצה פותחת את דף הפרויקט |

## פעולות נפוצות

1. **אישור / דחיית החלטה** — בעל סמכות רואה כפתורי "✅ אשר" ו"❌ דחה".
2. **הוספת פידבק** — ציון 1-5 (⭐ כישלון ועד ⭐⭐⭐⭐⭐ מצוין) + הערה "מה קרה בפועל". הציון משפיע על ניתוחים עתידיים.
3. **סימון כלא רלוונטית** — כפתור ⛔ על הכרטיס. אפשר להחזיר. סינון "רלוונטיות" מציג רק רלוונטיות, רק לא רלוונטיות, או הכל.
4. **קישור לפרויקט** — כפתור 🏗 (למגיש ההחלטה ולמנהל מערכת). המערכת מציעה פרויקט מתאים, אבל הקישור נשמר רק אחרי שבחרת. ההחלטה תופיע בדף הפרויקט.
5. **צפייה בפרטים** — לחיצה על הסיכום פותחת חלון עם RACI ופידבק.
6. **סינון** — לפי סוג / סטטוס / פרויקט / רלוונטיות.

> **💡 איך לאשר בטלגרם:** לחיצה על ✅ או ❌. דחייה → שדה לסיבה.
