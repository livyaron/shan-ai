# 5. בוט הטלגרם

אותה לוגיקה כמו באתר — אבל בלי מחשב. שואלים, רושמים החלטות, מנהלים משימות ומקבלים דוחות תוך-כדי שטח.

## רישום ראשוני

1. קבל/י מהמנהל/ת את הקישור לבוט ו**קוד רישום אישי**.
2. פתח/י את הבוט ושלח/י `/register הקוד-שלך`.
3. הבוט יאשר: "✅ ברוך הבא" — ויופיע לך מקלדת קבועה בתחתית המסך.
4. כבר רשום/ה? `/status` מציג את שמך ואת התפקיד שלך במערכת.

## המקלדת הקבועה

| כפתור | מה הוא עושה | למי |
|---|---|---|
| 📁 פרוייקטים | חיפוש פרויקט ותצוגת הנתונים שלו | כולם |
| 📋 החלטות | ההחלטות שלך עם סינון, מה שממתין לאישורך, ⭐ החלטות שמחכות לדירוג | כולם, חוץ ממשתמשי צפייה |
| 📊 דוח שלי | הדוח השבועי האישי שלך | כולם, חוץ ממשתמשי צפייה |
| 🎯 חדר מבצעים | המשימות שלך (פרק 11) | כולם, חוץ ממשתמשי צפייה |
| 📊 דוח פרויקטים | הדוח האחרון שנשמר על הפרויקטים | כולם, חוץ ממשתמשי צפייה |
| 👥 דוח צוות | דוח שבועי לבחירת אחד מאנשי הצוות | מנהלי מחלקה ומעלה |

המקלדת נעלמה? `/menu` מחזיר אותה.

## שימוש יומיומי

| מה עשית | מה יקרה |
|---|---|
| שאלה ("כמה פרויקטים פעילים?") | תשובה ישירה + מקור, עם 👍 / 👎 |
| החלטה ("אני מחליט לעצור...", "יש לבצע...") | הבוט שואל "האם זו החלטה לתיעוד?" — ✅ / ❌ / 🧠 שמור כעובדה |
| החלטה שדורשת אישור | הבוט שולח לבעל הסמכות עם כפתורי "אשר / דחה" |
| 👎 על תשובה | הבוט שואל מה היה לא בסדר — התשובה שלך משפרת את המערכת |
| שליחת קובץ | הבוט שואל אם זה **קובץ מאסטר** (נתוני הפרויקטים) או קובץ רגיל ללמידה |
| "זכור ש..." | העובדה נשמרת בזיכרון הארגוני (פרק 10) |

## פקודות

- `/start` · `/menu` — תפריט ראשי ומקלדת
- `/decisions` — ההחלטות שלך · `/projects` — פרויקטים · `/missions` — חדר מבצעים
- `/report` — הדוח השבועי שלך · `/ask שאלה` — שאלה ישירה
- `/gold` — אישור תשובות זהב (מנהלים) · `/llm` — בדיקת תקינות ספקי ה-AI (מנהלי מערכת)

## איך המערכת מזהה החלטה

המערכת רואה את ההודעה, מקצה כיוון (שאלה / החלטה / שאלה כללית) דרך מודל שפה:

- **שאלה** — עונה ישר.
- **החלטה** — שואלת אישור: "האם זוהי החלטה לתיעוד?" גם ניסוח של מדיניות ("יש לבצע...", "נדרש ל...") מזוהה כהחלטה.
- **לא בטוחה** — שואלת שאלת הבהרה ("האם מדובר בפרויקט X או Y?")

> **⏳ ה-AI עמוס?** החלטה לא הולכת לאיבוד. אם מודל השפה לא זמין, ההודעה נשמרת בתור, מטופלת אוטומטית כשהוא חוזר, ואת/ה מקבל/ת את התוצאה בהודעה.
