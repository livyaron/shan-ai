# 14. הדשבורד הראשי — "תחנה חיה"

המסך הראשון אחרי הכניסה: ארבע תחנות, כל אחת עם המספרים החשובים של התחום שלה.

- 📋 — החלטות — 7 הימים האחרונים, מה ממתין לאישור
- 🎯 — משימות — פעילות, באיחור, חדשות
- 📂 — פרויקטים — אותם מספרים כמו בעמוד הדפוסים
- 📚 — לקחים — כמויות לפי סטטוס


## ניווט

| פעולה | איך |
|---|---|
| כניסה לתחנה | לחיצה על האריח — הוא מתרחב לתצוגה מלאה |
| מעבר בין תחנות | 1–4 או ← / → |
| יציאה | Esc או "חזור" בדפדפן |
| קישור ישיר לתחנה | הכתובת מתעדכנת (למשל `#projects`) — אפשר לשמור ולשלוח |


## שלי / כל האגף

מתג בראש המסך. **שלי** = המשימות שלך, הפרויקטים שלך, הלקחים שכתבת או שהוקצו לך. **כל האגף** = מה שכל משתמש רשאי לראות. המתג אף פעם לא מרחיב הרשאות — החלטות של כל האגף מוצגות רק למנהל מערכת.


## חי

- המספרים מתעדכנים לבד כל 45 שניות. החלטה חדשה מקפיצה הודעה קטנה.
- כל מספר בתחנת הפרויקטים לחיץ ופותח את רשימת הפרויקטים שהוא סופר.
- האנימציות ברקע (מפסק, שנאי, חצר מיתוג) הן קישוט בלבד — הן לא מציגות נתונים.
