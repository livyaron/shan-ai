# Main dashboard (/dashboard, "תחנה חיה")

<!-- Moved verbatim from the root CLAUDE.md on 2026-10-26. Loads only when Claude touches a matching file. -->

- **הדשבורד הראשי (`/dashboard`, "תחנה חיה"):** `_dashboard_stats` in `app/routers/dashboard.py` is the ONLY place its numbers are computed — the page renders it and `GET /dashboard/live` re-serves the same dict as JSON (polled every 45s; a new decision fires a toast + surge). The 7-day window is zero-filled (`DASHBOARD_DAYS`). `static/js/substation_bg.js` (the HV yard behind the page) is **decoration only**: it never shows a number or fetches anything; the page drives it through `window.SubstationBG` (`setLoad`/`setAlarm`/`surge`/`setRunning`). Motion is pinned from jsdelivr and optional — every value is in the HTML at rest, nothing waits at opacity 0. Every `data-live` key must be produced by `sbLiveValues` (a test enforces it). **ארבע תחנות + זום (2026-10-16):** the page is four tiles (החלטות · משימות · פרויקטים · לקחים); a tile zooms (Motion, clip-path from the tile's rect) into its full view — the decisions view is the original dashboard. `app/services/dashboard_domains.py` computes the other three inside `_dashboard_stats` (`stations` key), borrowing every definition (ACTIVE_STATUSES / NEW_MISSION_HOURS / war_room_kpis / stage_sectors / LATE_MONTHS); each station is isolated in a savepoint and returns `{"ok": False}` on failure. Sector counts are never summed (the donut's centre is `active`). `#<station>` in the URL opens it; Back/Esc close it; `1`–`4` and ←/→ switch. Lessons show counts only, no lesson titles. **שלי / כל האגף:** `dashboard_domains.resolve_scope` (URL `?scope=` → cookie `dash_scope` → admin=all, others=mine). "All" never widens access: decisions go division-wide for an admin ONLY (the decisions page shows everyone else just their own); missions/projects/lessons "all" = what every user already sees. "Mine" = missions `owner_id` · projects via `insight_access.sees_project` (same rule as the patterns page; never linked = 0, never everything) · lessons `created_by`/`assigned_to` ∈ the user's profiles + referent groups. **סצנות חיות:** `static/js/station_scenes.js` — decoration only like `substation_bg.js` (no fetch, no text; a test enforces it): scope (החלטות, fault spike while approvals wait) · breaker (משימות: ONE outdoor SF6 live-tank T-type breaker — steel structure, mechanism cabinet with position flag red=closed/green=open, support insulator, horizontal interrupter chamber; an interrupter in EACH arm opens together, and when open the current stops on BOTH sides — one series circuit (user corrections 2026-10-16); overdue lights an alarm lamp on the cabinet) · xfmr (פרויקטים: substation power transformer, bus → windings → bus — user: "we are substations", never transmission pylons) · globe (לקחים: ONE globe in the middle, fed by faint streams from both edges; touching the glass gathers the discharge to the finger; a press sends a ring). **No sticky bar while scrolling** (user: "not pretty") — instead `.zm-rail` (scene `rail`), a thin live conductor down the side of the zoom in the station's colour, fades in once the scene has scrolled out of view (`.zm.deep`) and quickens while scrolling; a canvas needs an explicit height (top+bottom does not stretch it). The zoom focuses `#zm-body` so ↓/PageDown scroll at once. Page scripts carry `?v={{ asset_v }}` (the deployed commit): a cached old `station_scenes.js` silently drew nothing for the new scene names. One canvas per tile + one banner per zoom view; the page feeds them through `stFeedScenes`. The שלי/כל האגף switch is a macro rendered twice (header + zoom bar). `html, body { overflow-x: clip }` is load-bearing: a 2px-wide RTL page made Chromium paint the fixed zoom shell shifted after zooming from the right column.
